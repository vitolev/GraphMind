Start of iteration:
├─ good_graphs_set has 1000 graphs (from previous iterations)
│  These are "promising candidates waiting to be evaluated"
│
├─ training_dataset has 5000 graph-score pairs
│  These are "graphs we already know the real performance of"
│
Generation + Screening:
├─ Generate 100,000 new graphs
├─ Run GNN (trained on training_dataset) to predict scores
├─ Select top 100 → ADD to good_graphs_set
│  Now good_graphs_set = 1000 + 100 = 1100 graphs
├─ Then enforce max size → keep last 1000
│  Now good_graphs_set = 1000 graphs
│
Selection for Evaluation:
├─ From good_graphs_set (1000 graphs), pick 50 best
│  (ones with highest predicted scores, never evaluated before)
│
Evaluation:
├─ Run LLM on those 50 graphs
├─ Get actual_score for each
│
Update Training Data:
└─ Add 50 new (graph, actual_score) pairs to training_dataset
   Now training_dataset = 5000 + 50 = 5050 pairs

Next iteration retrains GNN on these 5050 pairs!
